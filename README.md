
# Advanced Java Hotel Reservation Application

This project is a Java Spring Boot hotel reservation application with Angular frontend integration. It demonstrates advanced Java concepts including internationalization, multithreading, time zone conversion, REST endpoints, and Docker-based deployment support.

The application displays welcome messages in multiple languages, converts presentation times across time zones, and supports reservation-related backend functionality through a layered Spring Boot architecture.

## Highlights

- Built REST endpoints with Java and Spring Boot
- Implemented internationalized welcome messages using resource bundles
- Used Java threads to load multilingual messages concurrently
- Added time zone conversion logic for Eastern, Mountain, and UTC times
- Integrated Angular frontend assets with the Spring Boot application
- Added Docker support for containerized deployment
